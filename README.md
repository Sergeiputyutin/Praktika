# Метод шейкерной сортировки

## Участники проекта

1. Соколов Олег (Анализ и реализация алгоритма)
2. Путютин Срегей (Разработка интерфейса пользователя)
3. Хмельков Максим (Проведение тестирования программы)

## Идея проекта

Проект представляет собой реализацию алгоритма **шейкерной сортировки** на языке C++. Программа включает:

- Генерацию случайных чисел в заданном диапазоне
- Сохранение данных в файл
- Чтение данных из файла
- Сортировку методом шейкера
- Проверку корректности сортировки
